# 分享、任意股票回测与结构全开（2026.11.10.3）

## 故障原因和结果

截图选择了新华传媒sh600825、5日K、历史模式。旧自动计算入口只列举日线、若干分钟和周/月线，不使用已部署的TDX完整周期接口；顶部“信号回测”只切归档视图，没有提交成交回测，所以无预存归档的股票出现空白或失败。

现在无归档时直接请求TDX实时K线，5日/1分/季/年等周期走统一已支持的数据源。顶部和手机“信号回测”会提交当前股票当前周期的逐根回放及含成本模拟，完成后自动显示统计和逐笔交易。下方提供“当前周期回测”与“全周期回测”，没有主图或归档时也能提交；分钟分时按底层1分K，竞价缺少连续OHLC仍不造假。

完成任务记入平台临时磁盘上的最近结果，可在同一部署内其他浏览器读取；部署重启后临时结果可能清理。行级失败显示失败，混合任务显示部分失败，不能把失败周期算成全成功。

“分享实时图表”复制只包含股票、周期、data=live与版本的地址，不带本机后端设置、访问令牌或历史模式。旧archive链接在所选股票/周期无归档时也自动取数并切到实时。

## 大小和全开

默认同时开启“精细笔级观察”“线段大方向”“笔＋段叠加”，合并显示两套结构、中枢与候选；回测按当前选定的一套规则独立统计。颜色与标签区分笔级代理和递归结构，不降低确认门槛。

保留全部原始分型，用小K线/中笔端/大段端三档标记，三个开关互不排斥。大小来自当前结构端点归属，不是原文跨周期级别认证；段端形成中与已完成分开记录，大小证据时间可晚于原始分型。点击可看区间高低、幅度%、覆盖根数、所属结构；中枢标核心宽度%及跨度。默认显示全部分型价格，可关闭以减少拥挤。
