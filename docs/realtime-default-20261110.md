# 实时主图取数修复（2026.11.10.2）

默认打开主图从TDX行情源获取K线，交易时段报价每10秒、K线每15秒轮询；休市每300秒，页面隐藏暂停，回到前台立即取数。形成中K线继续显示，结构只使用已收盘K线。休市期间行情不变不代表取数停止。

根因：上版全周期回测组件发现历史输入哈希相同后，会自动载入保存明细；明细替换主图bars。后台持续轮询时，主图仍被这份固定历史覆盖。

已移除自动载入明细，只在点击“查看点位”后切到固定回放。实时按钮、返回实时结构、立即刷新和顶部/手机看盘入口均退出回放并恢复行情；切股票/周期/笔段口径会清除此前选中的历史。查看历史时暂停主图自动轮询，状态明确说明图表固定。

“立即刷新”使用refresh=true，跳过后端图表短缓存并重新请求TDX，响应禁止浏览器缓存。普通自动请求仍使用短缓存合并。保留回测文件和全部真实结果。
